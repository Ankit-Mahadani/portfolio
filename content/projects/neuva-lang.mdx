Most ML language projects are demos — syntax toys that print "hello world" and stub out the hard parts. Neuva is not that. It trains real PyTorch models, detects CUDA, runs mini-batch training loops, and saves weights to disk. The language is the interface; the execution is real.

## Why build a new language

Every ML project starts with the same 30-line PyTorch boilerplate: import torch, define a class, write `__init__`, write `forward`, write the training loop, handle the device, shuffle the data. None of that is the interesting part. Neuva eliminates all of it.

<Pull>Five lines to define, train, and evaluate a neural network — not a mock, not a wrapper around scikit-learn, actual PyTorch under the hood.</Pull>

The goal wasn't to wrap PyTorch in a pretty API. It was to design a language where ML concepts are first-class syntax — `model`, `layer`, `train`, `predict`, `save` are keywords, not function calls on imported modules. The compiler handles everything else.

## How it works

Neuva has a full compiler pipeline: a hand-written tokenizer feeds a Lark Earley parser that builds a typed AST, which a tree-walking interpreter evaluates. The interpreter maps each AST node to PyTorch operations at runtime — `layer dense(8 -> 32, relu)` becomes `nn.Linear(8, 32)` plus `F.relu`, stitched together into an `nn.Sequential` model.

## The language & custom loss

Neuva reads like English pseudocode, compiles like a real language. Type inference handles the common case; explicit annotations are available when you need them. You can define custom functions — including custom loss functions with mathematical penalties — and pass them directly to the training engine:

```
# Define a loss function in Neuva itself and use it during training
model Regressor {
    layer dense(8 -> 32, relu)
    layer dense(32 -> 16, relu)
    layer dense(16 -> 1, linear)
}

fn my_loss(pred, target) {
    # Penalize errors a bit more than plain MSE
    return mse(pred, target) * 1.2
}

let data = load("housing.csv")
let data = data.normalize()
let train_data, test_data = data.split(0.8)

train Regressor on train_data for 15 epochs, lr = 0.001, loss = my_loss

predict Regressor on test_data
print Regressor
```

That's a multi-layer neural regressor with a custom mathematical loss function written directly in Neuva syntax — no PyTorch loss subclassing, no manual gradient wiring. The equivalent PyTorch is ~40 lines.

## What's next

The roadmap post-1.0 includes a VS Code extension with syntax highlighting, an ONNX export path (`export MyNet to "model.onnx"`) for production deployment, and a standard library of common datasets. The language is intentionally minimal right now — every feature that gets added has to pay its weight in reduced boilerplate.
